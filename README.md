#  Marrakech Restaurant App

Une application Android pour découvrir les restaurants de Marrakech.

##  Fonctionnalités

-  Carte des restaurants
-  Consultation des menus
-  Notation et avis
-  Authentification Firebase

##  Technologies

- JAVA
- Android SDK
- Firebase
- Gradle (KTS)

##  Installation

1. Clone le projet :
git clone https://github.com/Hanane-ELFADIL/MarrakechRestaurantApp.git

2. Ouvre dans Android Studio

3. Ajoute ton propre `google-services.json` dans `/app/`

4. Lance l'app ▶

## ⚙️ Configuration Firebase

1. Va sur [Firebase Console](https://console.firebase.google.com)
2. Télécharge `google-services.json`
3. Place-le dans `/app/`
