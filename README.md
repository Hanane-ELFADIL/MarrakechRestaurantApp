# 🍽️ Marrakech Restaurants Management Mobile App

##  Overview

The **Marrakech Restaurant Mobile App** is an Android application developed in Java that enables users to explore, manage, and interact with restaurant data in Marrakech.

This project was developed as part of an academic initiative to demonstrate practical skills in mobile application development, user interface design, and data management within the Android ecosystem.

---

##  Objectives

* Design and develop a functional Android mobile application
* Provide an intuitive interface for restaurant exploration
* Implement structured data handling within a mobile environment
* Apply best practices in UI/UX and mobile architecture

---

##  Features

* Display a list of restaurants
* View detailed information for each restaurant
* Visual representation of restaurant content
* Simple and intuitive navigation between screens
* Responsive and user-friendly interface

---


##  Chatbot Feature

The application includes an integrated chatbot designed to enhance user experience by:

* Answering questions about restaurants
* Helping users navigate the app
* Providing quick recommendations
* Improving interaction and accessibility

##  Application Architecture

The application follows a modular Android architecture:

* **Activities**: Manage UI and user interaction
* **Layouts (XML)**: Define visual components
* **Data Layer**: Handles restaurant data
* **Navigation Flow**: Structured transitions between screens

---

##  Technologies Used

* **Programming Language**: Java
* **Framework**: Android SDK
* **UI Design**: XML Layouts
* **Build Tool**: Gradle
